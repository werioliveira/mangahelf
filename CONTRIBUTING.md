# Contribuindo

Bem-vindo ao MangaShelf. Leia o AGENT.MD (modo ponytail) e as skills em skills-mangashelf/ antes de propor mudancas.

## Como contribuir
1. Abra uma issue discutindo a proposta.
2. Crie um branch a partir de main.
3. Implemente a menor mudanca completa que resolve o problema.
4. Adicione testes para logica nova nao-trivial.
5. Abra um PR e aguarde revisao.

## Padroes
- Commits em portugues ou ingles, curtos e objetivos.
- Migrations: up.sql + down.sql, reversiveis, cabecalho obrigatorio.
- Sem dependencias novas para poucas linhas.
